# WebTube

A lightweight YouTube-inspired video browsing interface built with HTML, CSS, and JavaScript.

## Run locally

Open `index.html` in your browser. No build step is required.

## Files

- `index.html` — page structure and WebTube branding
- `style.css` — layout, styling, and responsive behavior
- `script.js` — video browsing interactions
- `favicon.svg` — custom WebTube browser icon
